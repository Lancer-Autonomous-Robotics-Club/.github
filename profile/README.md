# Lancer Autonomous Robotics Club (LARC)

Official GitHub organization for the **Lancer Autonomous Robotics Club** at the University of Windsor — a student-run team building autonomous robotic systems.

## 🚀 What we do
- **Software** — Computer vision, ground control, data processing, CI/CD pipelines
- **Electrical & Avionics** — PCB design, KiCad libraries, embedded hardware
- **Mechanical** — 3D CAD, structural simulation, manufacturing
- **Controls** — Simulation and autopilot control systems

## 📁 Repositories
| Repository | Purpose |
|---|---|
| `larc-software` | Computer vision, ground control, data processing, CI/CD |
| `larc-electrical-avionics` | Central hardware design repository (KiCad libraries) |
| `larc-mechanical` | CAD models, structural simulations, manufacturing drawings |
| `larc-controls` | Flight simulation and autopilot control software |
| `junior` | Discord role-automation bot *(archived)* |
| `website` | Club website *(archived)* |
