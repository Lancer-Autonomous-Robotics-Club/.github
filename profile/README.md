# Lancer Autonomous Robotics Club (LARC)

Official GitHub organization for the **Lancer Autonomous Robotics Club** at the University of Windsor — a student-run team building autonomous robotic systems.

## 🚀 What we do
- **Software** — Computer vision, ground control, data processing, CI/CD pipelines
- **Electrical & Avionics** — PCB design, KiCad libraries, embedded hardware
- **Mechanical** — 3D CAD, structural simulation, manufacturing
- **Controls** — Simulation and autopilot control systems

## 🧭 New member guide

1. **Get access** — Ask a club lead for an invite to this GitHub organization and to your workstream's team.
2. **Join the Discord** — Role assignment and nickname sync are automated by our `junior` bot (`/link` your GitHub, then `/ascend`).
3. **Clone your repo** — Each active repository has a README describing its focus areas. Start there.
4. **Introduce yourself** — Say hi in Discord and tell the team which workstream you're joining.

## 🤝 How we work

- **Default branch is `main`.** Never push directly to `main` — work on a branch.
- **Branch naming** — `feature/short-description` for new work, `fix/short-description` for bug fixes.
- **Pull requests** — Open a PR against `main` and request a review from your workstream lead before merging.
- **Keep it clean** — One concern per PR, descriptive commit messages, and update the README if your change affects how others use the repo.
